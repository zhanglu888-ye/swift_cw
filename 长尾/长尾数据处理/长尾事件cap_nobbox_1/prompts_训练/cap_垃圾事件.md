#### **# 核心任务**
你的任务是分析<image>中与“垃圾事件”相关的情况。
#### **# 分析与描述的核心流程**

**A. 背景知识与分析框架（内置知识库）：**
你将严格依据以下知识库进行分析，但最终输出的描述中**不应直接引用**规则条文或编号。

* **事件定义**

  | **事件类别**      | **核心定义**                                                 | **关键视觉特征**                                             | **触发条件（判定规则）**                                     | **易混淆场景排除**                                           |
  | :---------------- | :----------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
  | **1. 垃圾桶满溢** | 公共区域的垃圾容器因容量不足或使用不当，导致垃圾在其**外侧散落堆积**，或**超出其物理容纳边界**（如高出桶口、堆放在顶盖上）。 | 可见1个或多个**垃圾容器**；容器周边**地面**有明显垃圾；容器内垃圾**堆积高度超过桶口**；容器盖**闭合但顶部有垃圾**。 | **满足以下任一情况：**<br>1) 容器周边地面有明显的散落/堆积垃圾；<br>2) 容器盖已闭合，但其**顶部**有垃圾堆放；<br>3) 容器盖开启或无盖，内部垃圾的**堆积高度已超过桶口平面**（单个长条状物体超出亦算）。 | 保洁作业中、垃圾集中在**清洁工具内**；居民**正投放**造成瞬时外露。 |
  | **2. 垃圾堆积**   | 未见垃圾容器的公共区域出现**明显垃圾堆**。                   | 地面上有**多件垃圾组合成堆**；垃圾堆旁边**无可对应的垃圾容器**。 | 画面范围内**未出现**可明确对应的垃圾容器。                   | 零星1–2件小垃圾；**有围挡/标识**的施工材料临时堆放且摆放有序；保洁暂存且集中于**作业工具/车辆**内。 |

* **风险等级**

  | **风险等级** | **判定标准（满足任一项即可）**                               |
  | :----------- | :----------------------------------------------------------- |
  | 3级 - 高风险 | 明确阻断消防通道、机动车道或医院/学校等关键出入口。含有明显危险/污染物。垃圾已进入排水口/河道。垃圾容器倾覆，散落覆盖主通道。 |
  | 2级 - 中风险 | 明显干扰人流/车流秩序，迫使绕行但未完全阻断。位于人流密集公共空间形成显著脏乱差面。大件垃圾或成片堆放长期压占盲道/无障碍通道。 |
  | 1级 - 低风险 | 已构成违规堆放，但位于非关键通行区域，影响范围有限。孤立大件垃圾放置，对通行影响轻微。垃圾桶满溢但散落较少、对主通道影响不明显。 |
  | 0级 - 无风险 | 符合排除条件或难以从单帧图像确定异常。                       |

* **排除条件**

  | **场景类型**  | **垃圾堆积排除条件**                                   |
  | :------------ | :----------------------------------------------------- |
  | 环卫作业中    | 环卫人员正在归集/清运，现场可见作业车辆/工具。         |
  | 合规施工      | 有围挡/告示/警示标识的工地范围内，材料或废料整齐堆置。 |

**B. 描述原则与风格 (通用):**

*   **思维链（CoT）核心**：你的分析必须层层递进，从观察到推理，再到结论。
*   **结构化描述**：严格按照输出规范中对 `simplified_cot` 和 `detailed_cot` 的结构要求进行撰写。
*   **展示而非告知 (Show, Don't Tell)**：通过描述视觉证据来支撑你的结论。
