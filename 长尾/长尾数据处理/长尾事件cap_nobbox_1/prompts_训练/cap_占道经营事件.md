#### **# 核心任务**
你的任务是分析<image>中与“占道经营”相关的情况。
#### **# 分析与描述的核心流程**

**A. 背景知识与分析框架（内置知识库）：**
你将严格依据以下知识库进行分析，但最终输出的描述中**不应直接引用**规则条文或编号。

*   **事件定义**

| **事件类别 (场景分类)** | **核心定义**                                                 | **关键视觉特征**                                             | **触发条件（判定规则）**                                     | **易混淆场景排除**                                           |
| :---------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **流动摊贩**            | 无固定店铺依托，使用**移动载具或以地摊形式**在公共区域从事经营活动。 | 手推车、三轮车、摊车、折叠桌、地布、遮阳篷、挑担等移动设施；**商品成组陈列**用于销售。 | 同时满足：①经营设施位于**公共通行面**；②出现**陈列/加工/交易**任一；③对通行有**明显占用**。  | 规范集市内经营；公益宣传活动；搬家/装卸等**非经营性**的短时物品停放。 |
| **出店经营**            | 依托固定商铺，但其经营性物品或活动**超出店铺的合规物理边界**，侵占了外部公共区域。 | 可见清晰的店铺门面（门、窗、招牌）；门外公共区域有货架、商品、桌椅、广告牌等；**部分门店前有台阶**。 | 需识别出固定门店，并满足以下**任一**占道条件：<br>1. **无台阶门店**：经营性物品/设施的任何部分**越过门框的垂直地面投影线**。<br>2. **有台阶门店**：经营性物品/设施的任何部分**接触到最底一级台阶以外的公共地面**。 | 店铺装修（有围挡/标识）；**仅在店铺私有台阶上**摆放的物品；物业划定的、未越界的外摆区域。 |

*   **风险等级**

| 风险等级       | 判定标准                                                     |
| :------------- | :----------------------------------------------------------- |
| **3级-高风险** | 关键通道（消防、急救、交通主干道）被阻断；存在明火/燃气/油锅等直接安全隐患；在学校/医院等敏感区域违规设摊；现场人群高度拥挤，秩序混乱。 |
| **2级-中风险** | 位于主通行路径并造成明显绕行或持续拥挤；店外外摆对人行道/盲道造成明显受限；多点连片出现，严重影响街面整体秩序。 |
| **1级-低风险** | 位于背街小巷或区域边缘，对主通行影响轻微；外摆规模小，占用空间有限，行人可轻松绕行；流动摊贩短时停留。 |
| **0级-无风险** | 许可区域内合规经营；或非经营性的临时占用，未对公共秩序造成实质影响。 |

*   **排除条件**

| 场景类型          | 排除条件                                                     |
| :---------------- | :----------------------------------------------------------- |
| **功能性行为**    | 施工、搬运、装卸、快递投递等作业行为；无商品陈列/价格牌/收款码/招揽等经营要素。 |
| **公益/非营利**   | 便民服务、社区活动等非营利性活动，未形成交易与盈利目的。       |
| **特殊人群/设备** | 残疾人代步车、老人助行器等必要性停放/通行。                    |

**B. 描述原则与风格 (通用):**

*   **思维链（CoT）核心**：你的分析必须层层递进，从观察到推理，再到结论。
*   **结构化描述**：严格按照输出规范中对 `simplified_cot` 和 `detailed_cot` 的结构要求进行撰写。
*   **展示而非告知 (Show, Don't Tell)**：通过描述视觉证据来支撑你的��论。
