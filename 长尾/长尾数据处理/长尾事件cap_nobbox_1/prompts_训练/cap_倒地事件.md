#### **# 核心任务**
你的任务是分析<image>中与“人员异常倒地”相关的情况。
#### **# 分析与描述的核心流程**

**A. 背景知识与分析框架（内置知识库）：**
你将严格依据以下知识库进行分析，但最终输出的描述中**不应直接引用**规则条文或编号。

*   **事件定义**

| **事件类别**     | **核心定义**                                                 | **关键视觉特征**                                             | **触发条件（判定规则）**                                     | **易混淆场景排除**                                           |
| :--------------- | :----------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **人员异常倒地** | 在**公共区域**出现**非休憩目的**的倒地/躺卧/俯卧/侧卧姿态。 | 身体与地面**大面积接触**；| 可见**清晰躺/趴/侧卧**姿态，且位置在公共通行区（非休息区）； | 瑜伽/露营/躺椅/座椅/草地休憩等**允许躺卧**的活动场景；儿童在游乐区短时趴卧；舞台/摄影摆拍在**非通行区**。 |

*   **风险等级**

| 风险等级       | 判定标准                                                   |
| :------------- | :--------------------------------------------------------- |
| **3级-高风险** | **高危事故现场异常倒地** (如车祸、施工意外、火灾现场)      |
| **2级-中风险** | **公共区域倒地 (无人看管)** (可能需要紧急医疗救助)         |
| **1级-低风险** | **不当场所躺卧/倚靠** (更偏向公共秩序问题，如流浪人员躺卧) |
| **0级-无风险** | **正常休息与活动** (符合排除条件)                          |

*   **排除条件**

| 场景类型         | 排除条件                                                     |
| :--------------- | :----------------------------------------------------------- |
| **休息区场景**   | 人员躺卧在**公园草坪、沙滩、指定的休闲躺椅**等明确的公共休闲区域 |
| **活动相关场景** | 人员的姿态与特定活动明确相关，如**瑜伽、街舞、俯卧撑、儿童玩耍打闹**等 |
| **短暂动作快照** | 图像抓拍到明显的**弯腰、下蹲**（如系鞋带、捡东西）的瞬间，身体未完全失去重心 |
| **比赛活动** | 拳击比赛、格斗比赛等赛事发生倒地等动作 |

**B. 描述原则与风格 (通用):**

*   **思维链（CoT）核心**：你的分析必须层层递进，从观���到推理，再到结论。
*   **结构化描述**：严格按照输出规范中对 `simplified_cot` 和 `detailed_cot` 的结构要求进行撰写。
*   **展示而非告知 (Show, Don't Tell)**：通过描述视觉证据来支撑你的结论。
