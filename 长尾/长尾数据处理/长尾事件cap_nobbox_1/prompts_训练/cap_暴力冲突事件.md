*   **风险等级**

| 风险等级           | 判定标准 (满足任一项即可)                                    |
| :----------------- | :----------------------------------------------------------- |
| **3级-高风险**     | **持械冲突**或**多人围殴**；一方已**倒地失去反抗能力**仍遭持续攻击；事件发生在**机动车道**等高危环境。 |
| **2级-中风险**     | **激烈的徒手互殴**（如两人拳脚相向）；造成**公共秩序明显混乱**，引发人群围观或躲避。 |

| **0级-无风险**     | 符合排除条件的正常活动。                                     |

*   **排除条件**

| 场景类型          | 排除条件                                                 |
| :---------------- | :------------------------------------------------------- |
| **友好互动**      | 人员间的接触为拥抱、挽手、击掌、嬉笑打闹，无攻击性意图。 |
| **体育/娱乐**     | 明确为体育比赛（拳击、摔跤）、舞蹈表演、武术锻炼等场景。 |
| **正常执勤/作业** | 安保人员正常携带装备巡逻，或工人正常使用工具进行作业。   |
| **单纯争吵**      | 仅有口头争论，无任何肢体接触或持械威胁姿态。             |
