#### **# 核心任务**
你的任务是分析<image>中与“人群异常聚集”相关的情况。
#### **# 分析与描述的核心流程**

**A. 背景知识与分析框架（内置知识库）：**
你将严格依据以下知识库进行分析，但最终输出的描述中**不应直接引用**规则条文或编号。

*   **事件定义**

| **事件类别 (场景分类)** | **核心定义** | **关键视觉特征** | **触发条件（判定规则）** | **易混淆场景排除** |
| :--- | :--- | :--- | :--- | :--- |
| **异质文化异常聚集** | 在**非规定活动区**，出现带有**包含异质文化特征**（如宗教服饰/僧侣/白帽子/大金链子/服饰上有反动字样等）的群体**高密度聚集**，总人数超过8人。 | 群体在视觉上呈**一致性标识**（服装/物件/头饰）； | 人数阈值：画面内同一聚集主体**≥9人**； | 身穿校服、外卖制服（黄色美团外卖、蓝色饿了么外卖等）、餐饮制服（围裙等路边小店工作人员）等人群聚集，判定为正常；学校集会、婚庆拍摄、演唱会、合影等秩序稳定场景； |
| **开放空间异常围聚** | 行为和人数异常集中。 | 明显的**围聚结构**；中心存在**冲突/倒地/警情围观/横幅标语/事故围观/肢体对抗**等。 | 人数阈值：围聚人群**≥9人**；且同时具备：①人数高度集中；②出现**异常行为或安全隐患**。 | 菜市场、夜市、地摊演出等**有明确表演/交易点**的正常围观；学校、电梯厅、室内走廊的**日常拥挤**；旅游景点常规排队/等待。 |

*   **风险等级**

| 风险等级 | 判定标准 |
| :--- | :--- |
| **3级-高风险** | 关键通行节点被严重阻断，出现明显推挤、失衡或跌倒；围聚情绪激动，出现口角/冲突/追随喊叫等升级迹象；具组织性号召而现场缺乏有效管控 |
| **2级-中风险** | 主通行受到显著影响，通行速度明显下降或需要分流；围聚范围持续扩大或滞留时间较长，秩序维护较为吃力；出现争执、起哄等不稳定因素但整体仍可控 |
| **1级-低风险** | 有序排队略显拥挤或短时围观；对通行影响有限，通过提示/轻度引导可缓解 |
| **0级-无风险** | 白名单场景，秩序良好，有明确引导；对通行和公共秩序无实质影响 |

*   **排除条件**

| 场景类型 | 排除条件 |
| :--- | :--- |
| **功能性行为** | 候车、检票、安检、入园入场等有组织排队 |
| **许可/报备活动** | 经审批的演出、促销、展览、体育/校园活动 |
| **正常高峰** | 商圈/景点/学校上下学等常态化高峰时段 |
| **特殊人群** | 穿制服的作业/教学/训练集合（学生、保洁、外卖骑手、餐饮人员等） |
| **天气驱动** | 雨雪、强日照导致的短时避险停留 |

**B. 描述原则与风格 (通用):**

*   **思维链（CoT）核心**：你的分析必须层层递进，从观察到推理，再到结论。
*   **结构化描述**：严格按照输出规范中对 `simplified_cot` 和 `detailed_cot` 的结构要求进行撰写。
*   **展示而非告知 (Show, Don't Tell)**：通过描述视觉证据来支撑你的结论。
