#### **# 核心任务**
你的任务是分析<image>中与“非机动车乱停放”相关的情况。
#### **# 分析与描述的核心流程**

**A. 背景知识与分析框架（内置知识库）：**
你将严格依据以下知识库进行分析，但最终输出的描述中**不应直接引用**规则条文或编号。


*   **事件定义与判定规则**

| **事件类别** | **核心定义** | **违规判定条件（满足任一项即触发）** | **豁免场景（非违规）** |
| :--- | :--- | :--- | :--- |
| **非机动车乱停放** | 非机动车在公共区域未按规定停放，或停放在禁止停放的区域。 | 1. **划线区域违停**：车辆未**完全**停放在停车标线框内，车身任何部分越过或压在标线上。<br>2. **无划线区域乱停**：在未设置停车标线的公共区域停放。 | 车辆处于被人员**骑行**、且明显处于动态行驶的状态。 |

*   **关键判定原则**
    *   **人车状态**：判定的核心在于车辆是否处于**停放状态或正在进入停放状态**。
    *   **无人乘坐**：车上无人乘坐即满足“停放”的基本前提。
    *   **停车过程**：人员在旁推行、整理车辆准备停放的行为，均视为乱停放过程的一部分，**属于正样本**。

*   **风险等级 (严重程度)**

| 风险等级 | 判定标准 |
| :--- | :--- |
| **3级-高风险** | **侵占关键设施**：车辆直接占用盲道、消防通道，或完全堵塞楼梯口/人行横道。 |
| **2级-中风险** | **严重影响通行**：在店铺门口、人行道等区域形成多车聚集性乱停，严重影响通行秩序和市容。 |
| **1级-低风险** | **轻度违规**：单辆车在非关键区域乱停，或车辆轻微越线，对通行有影响但尚可绕行。 |
| **0级-无风险** | **合规停放**：车辆完全停放在划线区域内，或场景中不存在违规停放行为。 |

**B. 描述原则与风格 (通用):**

*   **思维链（CoT）核心**：先观察车辆位置与地标（标线/盲道/店铺/绿化带）的关系，再应用判定规则，最后得出结论。
*   **结构化描述**：严格按照 `simplified_cot` 和 `detailed_cot` 结构撰写。

#### **# 输出格式规范**

你必须严格按照以下JSON结构进行输出。

*   **对于有异常情况**，`event_analyses` 列表中将包含一个或多个违规事件对象。
*   **对于无异常情况**，`event_analyses` 列表中将**只包含一个**代表全局场景分析的对象，其`异常类型`为 **"无异常"**，`风险等级`为 **"0级 - 无风险"**。

  "event_analyses": [

      },
      "detailed_cot": {

    }
